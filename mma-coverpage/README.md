## Design notes

- **Palette** — near-black base (`#040405`) with a single accent red ramp (`#ff5a52 → #e6191f → #7c0a0d`) and brushed-silver type gradients.
- **Type** — [Anton](https://fonts.google.com/specimen/Anton) for the display headlines, [Oswald](https://fonts.google.com/specimen/Oswald) for taglines and small caps. `WARRIOR` is red, `SPIRIT` is silver, so the two halves separate at a glance.
- **Texture** — grain, scratches and the distress on the headline are all generated in-browser with SVG `feTurbulence` filters (no bitmap textures), blended into the type via `background-blend-mode`.
- **Lighting** — three screen-blended spotlight cones plus lamp flares; the fighter is built from four mask layers off one silhouette (wide halo → tight rim → hot rim → body gradient) which is what produces the backlit red edge.
- **Grounding** — a blurred contact shadow under the planted foot plus a ground bounce glow, so the figure doesn't float.

## Editing

Everything is text in `coverpage.html`. The likely edits:

- Brand name: `.logo .apex` / `.logo .mma`
- Headline: the `.t-warrior` / `.t-spirit` spans
- Product line + strapline: `.fc`, `.banner`, `.micro`
- Contact block: `.cta`, `.socials`, `.url`
- Accent colour: the `--red*` custom properties at the top of the stylesheet

Re-render after editing:

```bash
npm install          # first time only (installs Playwright)
npx playwright install chromium
node render.js
```
